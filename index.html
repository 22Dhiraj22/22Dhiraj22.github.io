How I work

Data first, prototype early, write it down

My usual path from a request to a shipped feature. AI tools speed up each step; the judgement stays with me.

Understand the askFind out who's asking, what decision they're stuck on, and what "fixed" looks like.
Check the dataQuery the database before building, so assumptions are tested, not guessed.
Prototype in our UIClickable screens built on our own design system, so reviews are about the flow.
Write the PRDBusiness rules, edge cases, acceptance criteria, then PM and dev tickets in Jira.
Launch and explainRelease notes and user guides checked against the live system before they go out.
My AI setup: I've connected Jira, our databases and our analytics tool to Claude, and turned our design system into a reusable skill. Prototypes now match the production UI on the first draft, and data questions take minutes instead of a request to the tech team.
